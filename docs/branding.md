The graphic is an architectural wayfinding emblem with interlocking paths and an open passage. The shared `BrandLogo` component displays only the graphic, with the translated app name as its accessible image label. It uses a white silhouette in dark mode.

Both sections align at the top, with the complete composition centered vertically below the header. A compact stepped trail uses 32px icon markers and 24px offsets with practical instructions. The header uses a 32px logo, 44px utility targets, and 12px vertical padding, followed by 40px before the heading on mobile and tablet. Mobile retains centered headings and navigation links. Field labels, input text and cursors, account type choices, and terms all align left. It uses a 28px mobile title, 12px labels, 48px inputs and primary buttons, 8px label gaps, and 20px field gaps. Mobile heading-to-subtitle spacing is 12px and the form follows 28px below the subtitle. Input text remains 16px to avoid focus zoom on mobile. ## Final generation prompt

```text
Use case: logo-brand
Asset type: final standalone graphic identity for HousingFinder, a student housing and campus discovery app. The previous standard house icon was rejected as too generic.
Primary request: create a distinctive original wayfinding emblem, an abstract architectural ligature made from two interlocking folded paths. Two bold, asymmetrical right-angle ribbons turn inward around a clear open passage, suggesting navigating into a courtyard and finding one's own space. A clever compact near-square silhouette with a memorable offset opening, restrained softened outer corners, consistent broad stroke thickness, and unusually well-balanced negative space. It should feel designed as a unique brand glyph rather than taken from an interface icon library. Subtle architectural H/F-like structure is welcome, but no readable typography.
Style/medium: premium Swiss graphic identity, crisp flat vector-like solid charcoal #202124 on genuine transparency. Confident geometric construction, optically balanced. Strong enough to work as a 24px mark and to be recognizable alone.
Composition: just one isolated front-facing symbol centered on a square canvas, occupying 80% of canvas with even transparent margins. All negative spaces fully transparent.
Constraints: no literal house outline, roof, map pin, magnifying glass, key, compass rose, generic app badge, enclosing square border, text, words, readable letters, numbers, gradients, shadows, texture, mockups, multiple designs, color accents, or watermark. Preserve a single-color black-and-white identity.
```
